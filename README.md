# Sistemas Operacionais (Univali)

| Pasta | Avaliação |
| --- | --- |
| [`m1/`](m1/) | **M1** — Banco de dados com IPC (memória compartilhada) e pool de threads, em C. Ver [`m1/README.md`](m1/README.md) |
| [`m2/`](m2/) | **M2** — Simulador de escalonamento (FCFS, SJF, RR) com 1/4 CPUs e paginação sob demanda (FIFO/LRU), em C. Ver [`m2/README.md`](m2/README.md) e [`m2/RELATORIO.md`](m2/RELATORIO.md) |
| [`m3/`](m3/) | **M3** — Mini-sistema de arquivos em memória: árvore de diretórios, FCB/inode, permissões RWX com bitmask e alocação indexada de blocos, em C. Menu numerado e terminal estilo Linux. Ver [`m3/README.md`](m3/README.md) |

Tudo roda em Linux (GitHub Codespaces ou WSL) com `gcc` e `make`.
